# 如何使用 Agent Roadbook

先选一条能读完的路径，再把目录当成地图，而不是待办清单。

## 找到当前章节

左侧目录按模块分组，组内还有一层技术主题。点开标题就会进入对应页面，当前页会高亮。目录很长时，它在自己的区域里滚动。窄屏上，目录收进顶部的菜单按钮。

右侧是本页的标题目录，会跟着滚动位置变化。页底的「上一节 / 下一节」沿着整条路线移动。

顶部可以搜索、切换浅色和深色外观。搜索覆盖全部章节的标题与正文。

## 阅读一节

页面顶部会显示内容状态、难度和预计阅读时间。

- **已发布**：可以按正文学习，也是后面章节沿用的参照
- **初稿**：可以读，也可以做题。这一节还能继续写细。和参考资料里的官方文档不一致时，以文档为准
- **已审核**：有人核对过，仍然不代表你已经学完
- **待编写**：只有路线位置，正文还没写。当前目录里没有这种页面

读完后可以点「标记为已学」。这个标记和答题记录一起存在浏览器的 localStorage 里。侧边栏里已学的章节会多一个「已学」。

## 做自测

练习和文章分开存放。页面上出现练习，是因为这一节的题目文件关联了同一个知识点 ID。

- 选择题：选择后提交，会立刻看到对错、答案和解析，也可以重试
- 问答题：先写下自己的话，再对照参考答案和评分要点，并自己标记是否掌握
- 代码题：在文本框里改模板，复制到本地运行。页面不会执行 Python

问答题的原文和代码草稿只留在当前这页。刷新后，保留的是掌握程度和完成标记，不是你写过的文字。

## 进度

[学习进度](/guide/progress.md) 按模块汇总已学章节和已完成练习。你可以导出 JSON、在另一台浏览器导入，或清除全部记录。清除浏览器站点数据也会删掉这些记录。

## 按什么顺序读

打开 [学习路线](/guide/learning-path.md)。先读已经发布的三节，再沿同一条顺序进入其余章节。页顶的「初稿」不影响往下读。
