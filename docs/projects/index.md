# 实战项目

这里的项目不是一组外链。每一项都写出目标、步骤、任务清单和验收标准。业务代码留给你在本地实现，页面负责把完成情况记在浏览器里。

先做多工具 Agent，再做知识库问答。旅游规划把工具、计划和状态放在一起，适合前两个项目已经能自己讲清楚之后。

可以按难度或标签缩小列表。待编写的知识章节不会挡住项目页，但项目会链到它依赖的知识点。那些知识点如果还没有正文，先读项目里的任务说明，再用资源导航里的官方文档补术语。
